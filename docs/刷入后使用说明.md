# Pixel 6 Pro / AOSP 15：刷入后使用

这份说明对应本次融合编译的 R0dump Manager、Framework、libcore 和 ART。手机入口是 **R0dump 管理器**，使用设备主用户。

## 第一次捕获

1. 打开 **R0dump 管理器 → 应用**，搜索并选择目标应用。列表没有目标时点“重新扫描已安装应用”。
2. “配置方案”选 **默认值**，“进程模式”先选 **主进程**。
3. 打开 **高级**，按下表检查。其余预算和点位先保留默认值。
4. 返回“应用”，点 **启用捕获并启动**。如果界面显示“发布并启动”，该按钮也会发布配置并冷启动目标。目标旧进程会被结束，请先保存目标应用中尚未保存的内容。
5. 在目标应用里进入需要分析的页面、触发相关功能，让相应 DEX 和类被加载。首次可保持运行 30～60 秒；这是建议的观察时间，不是完成信号。
6. 返回管理器，点 **修复并导出最新产物**。记录导出统计和文件路径。
7. 导出后点 **结束会话**，停止本轮目标进程和捕获会话。

| 高级选项 | 第一次建议 |
| --- | --- |
| 启用 Manifest | 开启，保留组件范围信息 |
| 启用遍历 | 开启 |
| 遍历启动时机 | Application.onCreate 之后 |
| 遍历模式 | DEX 名称 |
| 遍历延迟（毫秒） | 5000 |
| 启用强制调用 | 开启 |
| 最大强制调用次数 | 先用 256；稳定后可尝试 1024 |
| ANR 保护 | 开启 |

**当前代码的“最大强制调用次数”默认是 1，不是全方法调用。** 256/1024 是本说明建议的试跑值，不是已对你的目标应用验证过的参数。主动处理受 Manifest 组件包名前缀、精确 selector、类/方法上限和调用预算约束；启用遍历不等于任意业务方法都会执行。此版 bit 41 使用 no-execute 路径，不执行所选方法体，但类初始化仍可能发生。

## 导出位置及查看

手机中的公开导出目录：

```text
/sdcard/Downloads/r0dump-exports/<目标包名>/<run_id>.zip
/sdcard/Downloads/r0dump-exports/<目标包名>/<run_id>.zip.sha256
```

目录名是 **Downloads**。电脑启用 ADB 并授权后，可以取回全部导出：

```bash
adb pull /sdcard/Downloads/r0dump-exports ./r0dump-exports
```

管理器显示“JADX 可用 DEX”大于 0 时，优先查看 ZIP 内修复后的 DEX；也可尝试用 JADX 打开 ZIP。包内还包含 base/split APK、Manifest 和修复证据。DEX 结构通过验证并不代表每个方法体都已恢复，仍需检查目标类和方法。

如果“JADX 可用 DEX”为 0，ZIP 是诊断证据包，不能据此判断脱壳成功。不要仅凭 ZIP 文件存在或 checksum 修复成功来判断结果。

原始捕获记录位于：

```text
/sdcard/Android/data/<目标包名>/files/r0dump-fusion/runs/<run_id>/process-<pid>/
```

普通文件管理器可能受 Android/data 访问限制，优先使用管理器导出。每次“启用捕获并启动/发布并启动”都会新建运行 ID；导出针对当前配置的运行，不会拿历史运行冒充本次结果。

## 常见情况

- **没有业务 DEX**：确认确实进入业务页面；若业务运行在远程进程，将“进程模式”改为“所有进程”后重新发布并启动。
- **加载较晚**：下一轮把遍历延迟改为 10000～15000 毫秒，并在延迟期间进入相关页面。已经错过的一次遍历不会因为修改草稿而自动重跑，需要重新发布并启动。
- **只有少量方法产物**：检查最大强制调用次数是否仍为 1，以及 Manifest 范围/精确 selector 是否覆盖所需代码；被动捕获与主动处理的数量不是同一个概念。
- **卡顿或崩溃**：下一轮先关闭强制调用，保留基础捕获以定位影响；然后逐项恢复。不要一开始全选 43 个点位。
- **导出失败或可用 DEX 为 0**：保留管理器的原始错误、当前运行 ID 和日志；不要先清空捕获目录。
- **找不到管理器**：先确认刷入的是包含此应用的本次系统镜像。仅刷 boot 镜像不会安装 Manager、Framework、libcore 和 ART 的这些改动。

电脑保存本模块日志：

```bash
adb logcat -d -s R0dumpFusion > r0dump-log.txt
```

本说明按当前源代码核对按钮和参数。用户已反馈刷入；尚未由本任务实际连接手机确认界面、目标应用捕获和恢复覆盖率。
