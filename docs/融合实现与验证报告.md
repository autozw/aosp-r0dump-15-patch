# R0DUMP + P6 FART：AOSP 15 / Pixel 6 Pro 融合实现与验证

本次授权的源码融合、缺失 libcore 桥接补全、整机编译和主机验证已完成。目标源码为 `/media/zwzw/AOSP/new-15`，基线 Android 15 `android-15.0.0_r14` / `AP4A.250205.002`，构建目标 `aosp_raven-ap4a-userdebug`。

用户于本任务中反馈已经刷入；本任务没有执行刷机，也没有连接设备验证真实目标应用。编译和主机测试成功不等于所有加固应用都可以完整恢复。

## 已完成的能力

| 部分 | 实现 |
| --- | --- |
| libcore 桥接 | 补全 dalvik.system.r0dump_Runtime、13 个 JNI 声明、ClassLoader/cookie 助手和 7 个 Java 加载路由；加入构建和 module-lib API stubs |
| ART / Framework | 接入 Fusion 捕获点、延迟 ClassLoader 遍历、Manifest 范围、no-execute 主动处理、异步队列和预算；适配 AOSP 15 的 ClassLinker、LookupClass 和解释器接口 |
| 内存 DEX | 加入有边界的映射内存读取，处理 ARM64 地址标签、不可读页和可读尾部，记录缺失范围与完整性 |
| P6 思路 | 保留构造期 DEX 大小证据，复用保留字段，不改变原 Size() 语义和对象布局 |
| 设备端重建 | 根据 runtime_view 重建 ID 表和段信息，修复 SHA-1 / Adler-32，并让重建结果参与对应 DEX 对象的 CodeItem 回填 |
| 导出正确性 | 传递 I/O 失败和缺失数据状态；只导出当前运行；checksum 成功不能把有缺失的数据升级为完整结果 |
| Manager / 产品 | 修复当前 AndroidX API 兼容，集成 Manager、root helper、relay、权限和 SELinux；保留已有 DeviceProfile / NikGapps 改动 |

额外修复了继承代码中的两个标准 DEX 问题：空 ID 表的 header offset 必须为 0；map_list 不应包含零长度 ID 表项。主机和设备端实现已同步。

P6 的深度执行模式没有作为本版本默认行为合入。默认 bit 41 阻止所选方法体执行；类初始化仍可能发生。bit 40 和 bit 42 默认关闭。主动调用次数当前默认 1，首次使用可参考 [刷入后使用说明](刷入后使用说明.md) 调整。
